## 💡 Development Philosophy

> *"Code is written for humans first, machines second. Clarity, maintainability, and intentionality matter as much as raw performance."*

**Architecture over shortcuts** — I invest in clean, scalable foundations before piling on features. Technical debt is a real cost.

**Documentation is code** — An undocumented API is an incomplete API. Good docs are a first-class deliverable.

**Security by default** — Auth, validation, rate limiting, and input sanitization are never afterthoughts. They're built in from day one.

**Ship, then refine** — Working software that solves a real problem beats perfect software that never ships. Iterate in production.

**Always be learning** — The ecosystem moves fast. Staying curious and investing in fundamentals (not just frameworks) is how you stay relevant.
